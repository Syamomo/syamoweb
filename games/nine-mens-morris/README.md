# ナインメンズモリス

木製の盤と白黒の駒で遊ぶ、日本語のブラウザーゲーム。CPU対戦（5段階）と、同じ端末を交互に操作する2人対戦に対応します。

## 起動

SYAMOWEBフォルダーから `node serve-portal.mjs` を実行し、次のURLを開きます。

http://127.0.0.1:4180/games/nine-mens-morris/

ES ModulesとWeb Workerを使うため、HTMLのダブルクリックではなくHTTP(S)経由で開いてください。ビルド・外部パッケージのインストールは不要です。`games/nine-mens-morris/` 内のファイルを原本として直接管理します。SYAMOWEBのトップページへのカード追加と外部公開は今回の作業に含めていません。

## 操作

- 配置：空き地点をクリック／タップ。
- 移動：自分の駒、移動先の順にクリック／タップ。ドラッグでも移動可能。
- 捕獲：ミル完成後、取りたい相手の駒をクリック／タップ。
- キーボード：Tabで盤へ移動し、矢印キーで地点を選択、Enter／Spaceで決定。Escapeで選択解除。
- CPU対戦は白（先手）／黒（後手）を選択可能。持ち時間なし。
- 対局はメモリー内だけに保持。再読み込み・ページ終了でリセット。

## 採用ルール

各9個、24地点、白先手、斜めの線なし。両者が全駒を配置するまで移動は禁止。以降は隣接する空き地点へ移動し、残り3個になった側だけ任意の空き地点へ飛行できます。

ミルの完成ごとに相手の駒を1個捕獲。相手の全駒がミル内の場合を除き、ミル内の駒は保護されます。一度崩したミルの再形成でも捕獲可能。2列同時完成でも捕獲は1個です。

未配置を含む残りの駒が2個になった側、または移動段階の自分の手番で合法手がない側が負け。勝敗判定を引き分けより優先します。

引き分けは、手番・盤面・未配置数が同じ局面の3回反復、または移動段階で捕獲なし50手（各25手）で自動判定。ミル完成時は捕獲を解決してから判定します。流派で異なる細則はゲーム内にも明記しています。

参照：

- [Morris — Standard Rules / Rule Details](https://nine-mens-morris.net/manual.html)
- [FlyOrDie — Nine Men's Morris Rules（捕獲なし50手）](https://www.flyordie.com/mill/rules)

## CPU

既存の `chess-game/src/ai/engine.ts` の初心者向け設計に合わせ、浅い探索と見落としの割合で5段階を作っています。ゲームが違うため棋力の等価性は保証せず、体感の強さは試遊で調整する前提です。

| レベル | 最大先読み | 小さな評価損失／中／大の選択重み |
| --- | --- | --- |
| 1 はじめて | 2手 | 10 / 45 / 45 |
| 2 やさしい | 2手 | 25 / 40 / 35 |
| 3 すこし考える | 2手 | 45 / 40 / 15 |
| 4 じっくり考える | 2手 | 65 / 28 / 7 |
| 5 チャレンジ | 3手 | 80 / 18 / 2 |

1手は配置・移動と、必要な捕獲まで含みます。評価は残り駒・ミル・ミルの直前の並び・可動性から計算。探索上限はLv.1–4が8,000局面、Lv.5が25,000局面、時間目標上限500ms。全候補の評価を終えた深さだけ採用します。Web Workerで計算し、開始ID・局面・手番・合法性をメイン側で再確認します。

## ファイルと検証

- `engine.js`：盤の定義、合法手、捕獲、勝敗、引き分け。
- `ai.js` / `worker.js`：CPU探索と別スレッドでの実行。
- `cpu-job.js`：非同期応答の失効・検証。
- `app.js` / `index.html` / `style.css`：表示、操作、対局設定。
- `tests/`：ルール・CPU・非同期応答の自動テスト。
- `TESTING.md`：今回の確認範囲。

このフォルダーで `npm test`、またはSYAMOWEBから `node --test games/nine-mens-morris/tests/*.test.js` を実行できます。
