# バックギャモン CPU対戦

既存の `games/backgammon` をコピーした、1人用の別ゲームです。元の対人版は変更していません。木製盤のCSS、駒、サイコロ演出、採用済みの2つのWAV音源を引き継いでいます。

SYAMOWEBルートで `node serve-portal.mjs` を起動し、<http://127.0.0.1:4180/games/backgammon-cpu/> を開きます。ビルドや追加パッケージは不要です。ES ModulesとWeb Workerを使うため、HTTPで開いてください。対象はPC・スマートフォンのChromeです。

## 対局

- あなたは白・下側、CPUは黒・上側。すべての表示が手前を向きます。
- 最初に初級・中級・上級・プロ級を選択。既定は初級です。
- 白黒1個ずつ振り、大きい目が先攻。その出目を最初の移動に使います。同点のみ振り直します。
- 人間は駒→移動先を選び、「手番を確定」。確定前の自分の移動は「1手戻す」で取り消せます。最後の上がりも確定前なら戻せます。
- CPUは自動で振り、1手ずつ約550ms間隔で移動し、手番・勝利を確定します。
- 「強さ」から新しい難易度を選んで開始すると新しい対局になります。キャンセルでは現在の対局を保持します。「はじめから」は確認後、同じ難易度で初期状態に戻します。
- ダイアログ中はCPUの移動を待機。リセット時は思考Worker・移動タイマー・サイコロ演出・音を中止します。
- 1局勝負。通常勝ち・ギャモン・バックギャモンを表示。キューブ・累積得点・保存機能はありません。
- CPU処理に失敗した場合は盤と出目を保持し、「CPUを再試行」を表示します。

## 4段階の考え方

| 設定 | 駒の選択 |
| --- | --- |
| 初級 | 進行距離と上がりを中心に評価し、大きな判断の揺らぎを加える |
| 中級 | ヒット、直接の被ヒット、ホームのポイント、アンカーなどの基本評価に判断の揺らぎを加える |
| 上級 | 全候補を評価。封鎖、間接的な被ヒット、駒の偏り、レース中の出目の無駄も考慮。意図的な揺らぎなし |
| プロ級 | 上級の評価で上位12候補を残し、各候補について相手の21種類の出目・全合法応手を調べ、相手が最善の応手を選ぶと仮定した期待値を比較 |

初級＝小学生、中級＝中学生、上級＝高校生という指定は強さの目安です。人間の年齢別実力やプロ選手相当を測定したものではありません。プロ級は本ゲームの最強設定で、意図的な弱体化・時間切れによる探索の打ち切りはありません。ただし手作りの評価関数と候補絞り込みを使うため、最善手や無ミスを保証しません。

探索の考え方は [GNU Backgammonの先読みの説明](https://www.gnu.org/software/gnubg/manual/html_node/What-are-Plies_003f.html) と [候補の絞り込みの説明](https://www.gnu.org/software/gnubg/manual/html_node/Introduction-to-move-filters.html) を参照しました。GNU Backgammon本体や学習済みモデルを組み込んだものではありません。

## サイコロの公平性

実際の出目は、既存版と同じ `crypto.getRandomValues()` と棄却法で生成します。0〜251の乱数バイトを6で割り、252〜255は捨てて引き直します。各面に42個ずつ割り当てられるため、剰余の偏りがありません。

この抽選関数に難易度・盤面・勝敗を渡しません。各ロール開始時に2個を1回だけ抽選し、演出中の仮の目とは分離します。CPUは現在の出目だけを受け取り、次の実際の出目を知りません。探索用の21通りは確率を計算するための仮定で、実際の抽選とは無関係です。非ゾロ目は2/36、ゾロ目は1/36で加重します。

## ファイル

- `engine.js`: 対人版のルールとUndo、および同じ移動規則による手番全体の候補生成。
- `cpu.js`: 難易度、評価関数、全出目を加重した先読み。
- `cpu-worker.js`: UIとは別スレッドで思考。
- `cpu-session.js`: Worker応答の全手検証、移動の待ち時間、セッション破棄、失敗時の再試行。
- `app.js`, `index.html`, `styles.css`: 一人用UI。
- `dice-animation.js`, `game-sounds.js`, `audio/`: 対人版からコピーした演出・音。
- `tests/`: 自動検証と難易度比較用の `benchmark.mjs`。

## 確認コマンド

SYAMOWEBルートから実行します。NodeがPATHにない場合は `C:\Users\SYAMO\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe` を使用できます。

```text
node --test games/backgammon-cpu/tests/*.test.js
node games/backgammon-cpu/tests/benchmark.mjs 40
node scripts/prepare-portal.mjs --index-only
```

検証結果と実機確認の範囲は `TESTING.md` を参照してください。トップページは `scripts/catalog.mjs` に1人用の別カードとして登録しています。
