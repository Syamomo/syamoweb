# バックギャモン

同じ端末を挟んで向かい合う、2人専用のバックギャモンです。白は画面の下、黒は上に座ります。木製盤と白黒の駒、日本語の操作欄を使います。

## 起動

SYAMOWEBのルートで `node serve-portal.mjs` を実行し、<http://127.0.0.1:4180/games/backgammon/> を開きます。既存のサーバーが起動中ならそのままアクセスできます。ビルド・追加ライブラリ・インストールは不要です。JavaScriptモジュールを使うためHTTPで開いてください。

通常のNodeがPATHにない環境では、次のPowerShellコマンドを使えます。

```powershell
& 'C:\Users\SYAMO\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' serve-portal.mjs
```

## 確定した仕様

- 同じ端末の2人対戦。CPU・オンライン対戦はありません。
- PCとスマートフォンのChromeを対象。スマートフォンは横画面を中心に、縦画面でも操作できます。
- 1局ごとの勝敗。ダブリングキューブ・累積得点・対局時計はありません。
- 駒を選び、移動先をタップ。1回の移動に出目を1つ使います。マウスクリックとキーボードのTab・Enter / Spaceにも対応します。
- 使える出目を最大限使い切れる移動だけを受け付けます。選択後の印は移動先の表示です。
- 出目を選択すると、同じ駒を複数の目で上げられる場合にその目を優先します。未選択なら小さい目を優先します。より大きい目の使用が必須となる場面では、ルール上の合法手を優先します。
- 「1手戻す（Undo）」はその手番の駒移動だけを1手ずつ戻します。ヒット、バーからの復帰、上がりも復元します。出目は変わりません。
- 手番が終わっても自動交代せず、「手番を確定」で交代。15枚目を上げても「勝利を確定」までは戻せます。
- 対局中の「はじめから」は確認画面を経てリセット。終了後の「もう一局」は新しい盤から開始します。
- ブラウザーの再読み込みで初期状態になります。対局保存は実装していません。

## ルール

[Backgammon Galoreの一般ルール](https://www.bkgm.com/rules.html)を参照しています。

標準の15枚配置、先攻決めの出目の利用、ゾロ目4回、出目の最大利用、1つしか使えない場合の大きい目優先、ヒット、バーからの復帰優先、ホームへの集合とベアオフ、余った大きい目でのベアオフを実装しています。最後に通常勝ち・ギャモン・バックギャモンを表示します。キューブやオプションの得点ルールは使いません。

## 構成と変更箇所

- `index.html`：盤の外枠、遊び方、リセット確認。
- `styles.css`：木製盤、駒、対面操作欄、横画面・縦画面のレイアウト。
- `engine.js`：DOMから独立したルールとUndo。すべての遷移で元の状態を保持します。
- `app.js`：タップ操作と画面表示。上下の操作欄を固定し、手番ごとの盤の回転は行いません。
- `tests/engine.test.js`：特殊ルール、Undo、対局全体の整合性のテスト。

ここを原本として直接管理します。静的配信用のファイルは `index.html`、`styles.css`、`engine.js`、`app.js` です。既存のサイト生成処理はこのフォルダーを上書きしません。トップページの作品カード追加や外部公開はこの実装には含めていません。

## テスト

SYAMOWEBのルートから実行します。

```text
node --test games/backgammon/tests/engine.test.js
node --check games/backgammon/engine.js
node --check games/backgammon/app.js
```

確認した範囲と未確認の範囲は `TESTING.md` に記録します。
