# 効果音

ユーザーの試聴・選択用に作成したオリジナルの合成音です。外部の録音やサンプル素材は使用していません。2026-09-27にサイコロ・駒ともにAを採用し、対局操作に接続しました。Bは比較用の音源として保存しています。

| ファイル | 候補 | 音の方向 | 長さ |
| --- | --- | --- | --- |
| dice-a.wav | サイコロA | 木のカラコロ。低めで乾いた響き | 1.32秒 |
| dice-b.wav | サイコロB | 軽いコロコロ。高めで明るい響き | 1.32秒 |
| move-a.wav | 駒A | 木のコトッ。はっきりした置き音 | 0.28秒 |
| move-b.wav | 駒B | やわらかいトン。控えめな低い音 | 0.28秒 |

形式は44.1kHz / 16bit / モノラルのPCM WAV。サイコロ音の最後の2つの着地は、画面の停止タイミング720ms・1080msに合わせています。

再生成：SYAMOWEBルートで `node games/backgammon/scripts/generate-sounds.mjs`。減衰する共鳴音とフィルターを通したノイズを合成しており、同じスクリプトから同じファイルを生成できます。
